## 4. Conversion Rates
- INR to USD = 0.012
- INR to EUR = 0.011

## 5. Features
1. Accept amount in INR.
2. Select target currency.
3. Convert INR into USD or EUR.
4. Display converted amount.
5. Handle invalid currency.
6. Support Enter key in the GUI version.
